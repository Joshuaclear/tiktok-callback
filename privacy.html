Privacy Policy — Josh YouTube Uploader

Effective date: November 17, 2026

Overview

Josh YouTube Uploader is a personal, single-user tool operated by Josh Butler. It runs locally on the owner's own computer and is used only to upload the owner's own videos to the owner's own YouTube channel. It is not a public service.

Information the app accesses

With the owner's authorization through Google OAuth, the app accesses the owner's YouTube account through the YouTube API Services, including basic channel information and the ability to upload and manage the owner's videos. Video files are read from the owner's local library on his own computer.

How information is used

Accessed information is used only to upload the owner's videos to his own channel and to check which videos have already been uploaded so duplicates are not posted. No information is sold, rented, shared with third parties, or used for advertising.

Storage

The app's OAuth refresh token is stored locally on the owner's own computer. The app operates no external servers and collects no data from any other person.

Google API Services

This app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. This app uses YouTube API Services; Google's privacy policy is at https://policies.google.com/privacy

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
